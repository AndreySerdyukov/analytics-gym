## Условие

Посчитай, какая доля покупателей сделала больше одного оплаченного заказа.

Верни одну строку: число покупателей, число повторных покупателей и их долю в процентах,
округлённую до двух знаков.

## Решение

```sql
WITH per_user AS (
    SELECT
        user_id,
        COUNT(*) AS orders_count
    FROM orders
    WHERE status = 'paid'
    GROUP BY user_id
)
SELECT
    COUNT(*) AS buyers,
    COUNT(*) FILTER (WHERE orders_count > 1) AS repeat_buyers,
    ROUND(100.0 * COUNT(*) FILTER (WHERE orders_count > 1) / COUNT(*), 2) AS repeat_share_pct
FROM per_user;
```

## Разбор

Знаменатель здесь — покупатели, а не все зарегистрированные пользователи. Метрика отвечает на
вопрос «удаётся ли удержать тех, кто уже купил», и подмешивать в неё тех, кто не купил ни разу,
означает считать совсем другую метрику — конверсию в покупку.

Почему `COUNT(*) FILTER (…)`, а не `SUM(CASE WHEN … THEN 1 ELSE 0 END)`: результат тот же,
но `FILTER` короче и не заставляет читателя проверять, что там в `ELSE`. Знать оба варианта
полезно — `FILTER` есть не во всех диалектах.

Ловушка с датами: доля повторных покупок сильно зависит от окна наблюдения. Пользователь,
зарегистрировавшийся вчера, физически не успел купить дважды, но в знаменатель уже попал.
Поэтому такую метрику обычно считают по когортам с одинаковым сроком жизни — иначе приток
новых пользователей будет её механически занижать, и это легко принять за ухудшение продукта.

Что спросят следом: как посчитать эту долю по когортам месяца первой покупки — тогда сначала
находят дату первой покупки на пользователя, а потом группируют по её месяцу.
