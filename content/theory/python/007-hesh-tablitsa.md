## Что ты будешь уметь после этого урока

- превращать двойной цикл в один проход;
- выбирать между `set`, `dict` и `Counter` под конкретную задачу;
- узнавать формулировки, за которыми всегда стоит хеш-таблица.

Паттерн 1 из 7. Шпаргалка по опознанию и порядок прохождения – в конспекте «Как опознать
паттерн».

Самый частотный приём вообще. Если бы можно было выучить только один – надо было бы учить этот.

## Признаки

- Нужно проверить «встречался ли уже такой элемент»
- Нужно найти пару или группу с заданным свойством
- Нужно посчитать частоты
- Нужно сгруппировать элементы по какому-то признаку
- В наивном решении есть двойной цикл, где внутренний **ищет** что-то

## Идея

Разменять память на время. Вместо того чтобы искать элемент повторным проходом за O(n),
запомнить его в словаре и находить за O(1).

**Ключевой мыслительный ход:** вместо «для каждого элемента ищу пару справа» – «для каждого
элемента проверяю, видел ли я нужную пару слева». Один проход вместо двух вложенных.

## Шаблоны

```python
# Шаблон А: «видел ли я уже»
seen = set()
for x in arr:
    if x in seen:
        return True
    seen.add(x)
return False

# Шаблон Б: «запомнить значение -> индекс»
index_of = {}
for i, x in enumerate(arr):
    need = target - x
    if need in index_of:
        return [index_of[need], i]
    index_of[x] = i

# Шаблон В: подсчёт частот
from collections import Counter
freq = Counter(arr)

# Шаблон Г: группировка по ключу
from collections import defaultdict
groups = defaultdict(list)
for word in words:
    key = tuple(sorted(word))     # ключ = признак группы
    groups[key].append(word)
return list(groups.values())
```

Какой шаблон брать, видно из вопроса, который задаёшь на каждом шаге:

| Что нужно знать про элемент | Структура | Шаблон |
|---|---|---|
| только факт «был ли» | `set` | А |
| что-то про него: индекс, позицию, сумму | `dict` | Б |
| сколько раз встретился | `Counter` | В |
| в какую группу попал | `defaultdict(list)` | Г |

## Разбор: Two Sum (LC 1)

> Дан массив и target. Вернуть индексы двух элементов, сумма которых равна target.

**Наивно:** два вложенных цикла, проверяем все пары – O(n²).

**Ход мысли:** для элемента `x` мне нужен элемент `target - x`. Поиск в массиве – O(n), а
в словаре – O(1). Значит, идя слева направо, я буду складывать увиденные элементы в словарь
и для каждого нового проверять, не лежит ли уже нужное дополнение.

```python
def two_sum(nums, target):
    index_of = {}                      # значение -> индекс
    for i, x in enumerate(nums):
        need = target - x
        if need in index_of:
            return [index_of[need], i]
        index_of[x] = i
    return []
```

Время O(n), память O(n).

**Почему это работает за один проход:** когда мы стоим на элементе i, в словаре лежат все
элементы левее. Если пара существует, мы обнаружим её, дойдя до её правого элемента. Порядок
обхода гарантирует, что мы не пропустим ни одну пару.

Здесь же видно, почему нужен именно `dict`, а не `set`: вернуть надо индексы, то есть мало
знать, что число встречалось, – нужно помнить, где именно.

## Карточки

### Q: В чём ключевой мыслительный ход паттерна «хеш-таблица»?

Заменить «для каждого элемента ищу пару справа» на «для каждого элемента проверяю, видел ли
я нужную пару слева». Увиденное складывается в словарь, проверка стоит O(1), и двойной цикл
превращается в один проход: O(n²) становится O(n) ценой O(n) памяти.

### Q: По каким признакам в условии видно хеш-таблицу?

Нужно проверить «встречался ли уже такой элемент»; найти пару или группу с заданным свойством;
посчитать частоты; сгруппировать элементы по признаку. Универсальный признак: в наивном решении
есть двойной цикл, внутренний виток которого что-то ищет.

### Q: Как выбрать между set, dict, Counter и defaultdict?

По тому, что нужно знать про элемент. Только факт «был ли» – `set`. Что-то про него, например
индекс или позицию, – `dict`. Сколько раз встретился – `Counter`. В какую группу попал –
`defaultdict(list)`.

### Q: Почему Two Sum решается за один проход и почему словарём, а не множеством?

Когда мы стоим на элементе i, в словаре уже лежат все элементы левее, поэтому существующая пара
обнаружится, как только дойдём до её правого элемента, – ни одна пара не теряется. Словарь,
а не множество, потому что вернуть надо индексы: мало знать, что число встречалось.

### Q: Как сгруппировать анаграммы за один проход?

`defaultdict(list)`, ключ – признак группы, одинаковый у всех её членов: `tuple(sorted(word))`.
Кортеж, а не список, потому что ключ словаря обязан быть хешируемым. В конце –
`list(groups.values())`.

### Q: Чем платим за хеш-таблицу и когда её не берут?

Памятью: O(n) дополнительно. Поэтому явное требование O(1) памяти в условии – сигнал, что
задачу ждут через два указателя. Плюс порядок: `set` его не хранит, и если ответ зависит
от порядка, нужен ещё список или словарь с индексами.
