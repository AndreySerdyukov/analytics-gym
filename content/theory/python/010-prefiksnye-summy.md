## Что ты будешь уметь после этого урока

- отвечать на запрос «сумма отрезка» за O(1);
- комбинировать префиксы с хеш-таблицей – это самая мощная связка на medium;
- понимать, когда скользящее окно не работает и нужны префиксы.

## Признаки

- Много запросов «сумма на отрезке [i, j]»
- «Количество подмассивов с суммой K»
- «Подмассив с суммой, делящейся на K»
- Нужна сумма подотрезка, но окно не подходит (например, есть отрицательные числа)

## Идея

Заранее посчитать массив `prefix`, где `prefix[i]` – сумма первых i элементов. Тогда сумма
любого отрезка находится за O(1):

```
sum(arr[i..j]) = prefix[j+1] - prefix[i]
```

## Шаблон

```python
def build_prefix(arr):
    prefix = [0] * (len(arr) + 1)      # prefix[0] = 0 - это важно!
    for i, x in enumerate(arr):
        prefix[i + 1] = prefix[i] + x
    return prefix

# сумма arr[i..j] включительно:
# prefix[j + 1] - prefix[i]
```

Лишний нулевой элемент в начале избавляет от отдельной обработки случая i = 0. Всегда делай так.

Однострочник через `itertools`:

```python
from itertools import accumulate
prefix = [0] + list(accumulate(arr))
```

## Разбор: Subarray Sum Equals K (LC 560)

> Сколько существует подмассивов с суммой ровно k? Числа могут быть отрицательными.

Окно тут не работает именно из-за отрицательных чисел: сумма не растёт монотонно при расширении
окна, и сжимать неоткуда.

**Ход мысли:** сумма подмассива `(i, j]` равна `prefix[j] - prefix[i]`. Нам нужно
`prefix[j] - prefix[i] = k`, то есть `prefix[i] = prefix[j] - k`. Стоя в точке j, нужно узнать,
**сколько раз раньше встречалось значение `prefix[j] - k`**. Это подсчёт – хеш-таблица.

```python
from collections import defaultdict

def subarray_sum(nums, k):
    count_of_prefix = defaultdict(int)
    count_of_prefix[0] = 1          # пустой префикс - чтобы засчитать подмассивы с начала
    running_sum = 0
    result = 0

    for x in nums:
        running_sum += x
        result += count_of_prefix[running_sum - k]
        count_of_prefix[running_sum] += 1

    return result
```

Время O(n), память O(n). Обрати внимание: сам массив `prefix` строить не обязательно – хватает
бегущей суммы, потому что каждое значение нужно ровно один раз.

Обрати внимание на `count_of_prefix[0] = 1` – без этого не засчитаются подмассивы, начинающиеся
с индекса 0. Это самая частая ошибка в этой задаче.

**Комбинация «префиксные суммы плюс хеш-таблица» – один из самых мощных приёмов на medium.**
Запомни связку. Меняется только то, что кладётся в словарь:

| Задача | Что в словаре |
|---|---|
| количество подмассивов с суммой k | префикс -> сколько раз встречался |
| подмассив с суммой, делящейся на k | остаток префикса по модулю k -> первый индекс |
| самый длинный подмассив с суммой k | префикс -> самый ранний индекс |

## Карточки

### Q: Как через префиксные суммы получить сумму отрезка за O(1)?

Заранее строится массив, где `prefix[i]` – сумма первых i элементов, и тогда
`sum(arr[i..j]) = prefix[j + 1] - prefix[i]`. Построение – один проход O(n), каждый последующий
запрос – O(1).

### Q: Зачем в массиве префиксов лишний нулевой элемент в начале?

Чтобы не обрабатывать отдельно случай i = 0. С `prefix[0] = 0` формула
`prefix[j + 1] - prefix[i]` работает для всех отрезков одинаково, включая начинающиеся с нуля.
Короткая запись – `[0] + list(accumulate(arr))`.

### Q: Когда скользящее окно не работает и нужны префиксные суммы?

Когда в массиве есть отрицательные числа: сумма перестаёт расти монотонно при расширении окна,
и непонятно, когда сжимать слева. Также префиксы нужны, когда спрашивают количество подмассивов
с заданной суммой или много раз запрашивают сумму на отрезке.

### Q: Как считается количество подмассивов с суммой k?

Сумма подмассива `(i, j]` равна `prefix[j] - prefix[i]`, значит нужно `prefix[i] = prefix[j] - k`.
Стоя в точке j, спрашиваем у словаря, сколько раз раньше встречалось значение `prefix[j] - k`,
прибавляем к ответу и записываем текущий префикс. Один проход, O(n) времени и памяти.

### Q: Что делает `count_of_prefix[0] = 1` и что будет без него?

Это учёт пустого префикса. Без него не засчитываются подмассивы, начинающиеся с индекса 0:
для них искомый `prefix[j] - k` равен нулю, а нулевой префикс в словаре не лежит. Самая частая
ошибка в задаче Subarray Sum Equals K.

### Q: Чем связка «префиксы плюс хеш» отличается в разных задачах?

Каркас один: идём одним проходом, спрашиваем словарь про нужное значение префикса, потом кладём
туда текущее. Меняется содержимое словаря: количество вхождений префикса – для подсчёта
подмассивов; остаток по модулю k – для делимости; самый ранний индекс – для самого длинного
подмассива.
